# Security policy

Ipasty stores what you copy, so security and privacy are taken seriously.

## Supported versions

Only the latest version on the [releases page](https://github.com/augusttogu/ipasty/releases/latest) receives security fixes.

## Reporting a vulnerability

**Do not open a public issue.** Use GitHub's [private security advisory](https://github.com/augusttogu/ipasty/security/advisories/new) and include:

- what you found and its impact (for example, history data exposed);
- steps to reproduce;
- your Ipasty and macOS versions.

You'll get a reply within **7 days**. When the fix is published you'll be credited in the advisory, if you wish.

## Good practices for users

- Keep Ipasty up to date.
- Delete any secret text you copied from the history (<kbd>⌘⌫</kbd>).
- Never share your GIPHY key or the contents of `~/Library/Application Support/Ipasty`.
